# Experimentos

`avaliar_metodos.py` (Sprint 3) compara os métodos e as combinações entre eles
na base sintética rotulada, usando precisão, recall, F1 e taxa de falsos
positivos. O resultado vai para `experimentos/resultados/metricas.csv`, com a
seed e os parâmetros usados.

Regra: nenhum número de desempenho vai para o artigo sem ter saído de uma
execução real deste script.
